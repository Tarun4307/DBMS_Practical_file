# DBMS_Practical_file

This repository contains the **DBMS (Database Management System) SQL experiments** performed during class/practical sessions.

The repository includes SQL queries and programs covering fundamental database concepts such as database creation, table operations, data manipulation, constraints, joins, functions, and other SQL concepts.

## 📚 Contents

The experiments in this repository cover topics such as:

* Database and Table Creation
* DDL Commands
* DML Commands
* DQL Commands
* SQL Constraints
* Primary Key and Foreign Key
* INSERT, UPDATE and DELETE Operations
* SELECT Queries
* WHERE, ORDER BY and GROUP BY
* Aggregate Functions
* SQL Joins
* Subqueries

## 🛠️ Technologies Used

* **SQL**
* **MySQL** / SQL-compatible database system
* **Git & GitHub**
